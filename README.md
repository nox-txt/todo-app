# 📝 ToDo アプリ

バニラJS（フレームワークなし）で作成したタスク管理アプリです。  
スマホのホーム画面に追加してアプリとして使用することもできます。

## 🔗 デモ

https://nox-txt.github.io/todo-app/

---

## ✨ 機能一覧

### タスク管理
- タスクの追加・編集・削除
- 優先度設定（高・中・低）
- 日付・時間指定
- メモ欄
- タスク繰り返し設定（毎日・毎週・毎月）

### カテゴリ
- カテゴリの作成・編集・削除
- アイコン・カラーのカスタマイズ

### 表示・その他
- カレンダー表示
- タスク検索・カテゴリフィルター
- 進捗バー表示
- タスク完了時の紙吹雪アニメーション
- PWA対応・オフライン対応

---

## 🛠 使用技術

| 技術 | 用途 |
|------|------|
| HTML / CSS / JavaScript | フロントエンド |
| LocalStorage | データ保存 |
| Canvas API | 紙吹雪アニメーション |
| Service Worker | オフライン対応 |
| PWA | ホーム画面インストール |

---

## 📱 インストール方法

1. スマホのSafari（iOS）またはChrome（Android）でデモURLを開く
2. 「ホーム画面に追加」を選択
3. ホーム画面のアイコンからアプリとして起動
